## 🚀 Featured Projects

### 💳 FinPay — Distributed Digital Wallet

A microservices-based digital wallet and transaction processing platform.

**Highlights**
- Built with **Java 21, Spring Boot 3 and Spring Cloud**
- Database-per-service architecture with **PostgreSQL**
- Event-driven communication using **Apache Kafka**
- Redis-based **idempotency** for transaction safety
- Atomic P2P transfers with **JPA optimistic locking**
- JWT authentication and Spring Security
- Resilience4j circuit breakers for fault tolerance
- Docker-based development infrastructure

**Tech:** `Java` `Spring Boot` `Spring Cloud` `Kafka` `Redis` `PostgreSQL` `Docker` `JWT`

[View Repository →](https://github.com/patilmrugesh/FinPay)

---

### 🔐 CloudVault — Encrypted File Storage & AI Document Q&A

A secure distributed file-storage platform with document intelligence capabilities.

**Highlights**
- AES-256-GCM encryption with unique keys per file
- **2 MB chunked and resumable uploads**
- Parallel file processing using Java `CompletableFuture`
- SHA-256 based file deduplication
- MinIO object storage with PostgreSQL metadata
- Redis for caching and supporting distributed operations
- JWT authentication and RBAC
- AI-powered document Q&A using **RAG**
- Supports asking questions and generating insights from uploaded documents

**Tech:** `Spring Boot` `React` `TypeScript` `MinIO` `PostgreSQL` `Redis` `AES-256-GCM` `RAG` `Docker`

[View Repository →](https://github.com/patilmrugesh/cloudvault)
