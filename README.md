## Featured Projects

### 01. FinPay — Distributed Digital Wallet

A microservices-based digital wallet designed around secure money movement, transactional integrity, and resilient service communication.

**Engineering Highlights**
- Designed a microservices architecture using Java 21, Spring Boot 3, and Spring Cloud.
- Implemented database-per-service isolation using PostgreSQL.
- Integrated Apache Kafka for event-driven inter-service communication.
- Implemented Redis-based idempotency to help prevent duplicate transaction processing.
- Used JPA optimistic locking to manage concurrent wallet updates.
- Implemented JWT authentication and Spring Security.
- Integrated Resilience4j circuit breakers for fault tolerance.
- Containerized supporting infrastructure using Docker.

**Stack:** `Java 21` `Spring Boot` `Spring Cloud` `PostgreSQL` `Kafka` `Redis` `Docker` `JWT` `Resilience4j`

[**Explore Repository →**](https://github.com/patilmrugesh/FinPay)

### 02. CloudVault — Secure File Storage & AI Document Intelligence

A secure file-storage platform combining encrypted object storage, resumable uploads, distributed processing, and retrieval-augmented document question answering.

**Engineering Highlights**
- Implemented AES-256-GCM encryption with unique per-file encryption keys.
- Developed chunked, resumable file uploads using 2 MB chunks.
- Used Java `CompletableFuture` for parallel file-processing workflows.
- Implemented SHA-256-based file deduplication.
- Integrated MinIO for object storage and PostgreSQL for metadata management.
- Used Redis for caching and supporting distributed operations.
- Implemented JWT authentication and role-based access control.
- Built a local RAG pipeline for document question answering using Ollama, embeddings, and pgvector.

**Stack:** `Java` `Spring Boot` `React` `TypeScript` `PostgreSQL` `MinIO` `Redis` `AES-256-GCM` `Ollama` `pgvector` `Docker`

[**Explore Repository →**](https://github.com/patilmrugesh/cloudvaultt)
